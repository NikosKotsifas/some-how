# Huashu Design Skill — Product-Designer-First Pipeline

Forces the agent to think and work like an art director and product designer before writing application code.

## 1. The 3-Direction Rule (Concept Exploration)
When asked to explore a new layout, section, or visual redesign:
1. Formulate **3 distinct visual directions** with clear typographic, spatial, and compositional contrasts (e.g., *Direction A: Stark Swiss Brutalist Grid*, *Direction B: Immersive Full-Bleed Cinema*, *Direction C: Tactile 3D Studio Stage*).
2. Render high-fidelity HTML/CSS previews when visual comparison is helpful so the user can choose from concrete visuals rather than abstract descriptions.

## 2. Authentic Brand Protocol
- Never use placeholder text (`Lorem ipsum`), fake AI-generated brand logos, or distorted screenshots.
- Pull real brand assets, exact SVG logos, authentic product photography, and real Greek/English copy from the client's actual site.
- Respect the original visual DNA and layout (`μορφή του σαιτ`) of every featured client.

## 3. High-Craft HTML/CSS Artifact Rendering
- Build pixel-accurate HTML/CSS compositions at 4K (`3840x2160` or `2752x1536`) and render via headless Chrome (`--headless=new --hide-scrollbars`) to produce crisp studio visuals with zero text artifacts.
