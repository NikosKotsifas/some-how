# Taste Design Skill — High-Agency Frontend Taste Engine

Breaks default LLM UI habits ("AI slop") and enforces intentional, agency-grade frontend craft.

## 1. Anti-Slop Ban List (Strictly Forbidden)
Never generate any of the following default AI patterns:
- Generic purple/indigo/cyan glowing gradients on dark backgrounds (`from-purple-500 to-indigo-600`).
- Generic 3-column symmetrical feature cards with Lucide/Heroicon circles at the top.
- Generic centered hero sections with a pill badge + 2-line gradient title + 2 rounded buttons unless specifically styled in the brand's brutalist/editorial system.
- Invented/hallucinated logos, fake testimonials, or generic Unsplash stock office photos.

## 2. Intentional Agency Craft (Required)
1. **Tension & Asymmetry**: Pair massive, tight-tracked display typography (`Syne` / `PP Neue Montreal`) against ultra-crisp monospace technical indices (`[ 01 ]`, `TC 00:04:12`, `IBM Plex Mono`).
2. **Tactile Materiality**: Combine raw architectural textures (concrete, travertine, basalt, brushed aluminum) with glossy 3D sculptural objects (mylar balloons, chrome foil, bubble wrap, inflatables).
3. **Choreographed Reveal**: Every image and section should enter with intentional pacing — clip-path masks, parallax depth offsets, and smooth lerped cursor feedback.
4. **Real-Browser Audit**: After changing any frontend style or layout, inspect the rendered result in a real browser viewport to verify alignment, contrast, and visual rhythm.
